# NutriHealth — Project Skill

## Project Overview

**NutriHealth** is a web application for nutrition tracking and personalised meal
recommendation. Users can photograph meals to get calorie estimates, receive
AI-generated meal suggestions, track macros on a dashboard, and chat with an
AI nutrition coach.

### Core features
| Feature | Technology |
|---|---|
| Food image recognition | YOLOv8 + CLIP |
| Calorie / macro estimation | Portion estimator + USDA/Edamam API |
| Meal recommendation | Collaborative Filtering + content-based hybri
