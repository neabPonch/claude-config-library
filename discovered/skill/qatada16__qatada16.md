# Portfolio Build Skill

## Goal
Deliver a complete, single-page, vibecoded portfolio + resume route using Next.js, TypeScript, Tailwind CSS, and shadcn/ui with high visual quality, responsive behavior, strong interactivity, and dark/light modes.

## Source of Truth
- Content data: about/Aboutme.json
- Image assets: images/
- Required profile image: images/Q2.png
- Required favicon: images/Q2.ico
- Required current project thumbnails: images/neurachat.png, images/talkcart.png

## Non-Negotiables
- Use Tailwind CSS (not plain CSS-driven architecture).
- Use multiple shadcn/ui components (minimum 10 distinct component types).
- Main portfolio is a single-page layout.
- Must include dark/light mode with system-aware initialization.
- Must be fully responsive (mobile-first).
- Hero section must be visually premium and include Q2.png.
- Provide Resume button leading to a dedicated URL parameterized route.
- Resume page must support download as PDF or image.
- Add meaningful hover effects on nearly all interactive UI.
- Add multiple interactive 3D-like effects and aesthetic scroll animations.

## Preferred Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Moti
