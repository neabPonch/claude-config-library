# Luxury Frontend Design & Animation Playbook

## Context & Vision
Apply this skill whenever building a client-facing mockup that needs to look expensive, exclusive, and visually flawless. Reject standard blue/purple gradients, generic boxes, and basic system fonts.

## 1. Typography Core Principles
* Headings must strictly use elegant, premium Serif fonts (e.g., "Cormorant Garamond", "Playfair Display").
* Body copy must use clean, highly readable Sans-serif fonts (e.g., "Inter", "Plus Jakarta Sans").
* Maintain extreme tracking (letter-spacing) on uppercase navigation or sub-headings.

* Enforce extensive padding and margin rules. Use viewport widths (`8vw` to `10vw`) for page margins.
