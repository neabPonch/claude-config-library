# PXMeter Agent Skill

> **EXTREMELY IMPORTANT: DO NOT SCAN FOR FILES**
> Under NO circumstances should you use `find`, `Glob`, `ls -R`, or `Task/Explore` subagents to search for missing `.cif` or `.json` evaluation files. The dataset storage contains millions of structures, and any recursive search will completely crash or hang the session. If you don't know the exact path, you MUST construct it via `$PXM_MMCIF_DIR` or immediately ask the user. DO NOT GUESS.
