# CLAUDE.md - Wiley-VCH "For Dummies" Knowledge Transfer Template

## Project Overview

This project creates a comprehensive LaTeX template based on the Wiley-VCH "For Dummies" book series design philosophy. The template is designed for creating internal knowledge transfer documentation for colleagues in a "for dummies" style, covering:

- SQL (Structured Query Language)
- Shell Scripting
- Perl Scripting
- Company-specific Application

The template combines professional design with accessibility, using the iconic yellow-black color scheme of the "For Dummies" brand, along with additional topic-specific accent colors.

## Key Project Goals

1. ✨ Create an accessible, visually appealing knowledge transfer document
2. 🎨 Implement authentic "For Dummies" design elements (icons, colors, boxes, structure)
3. 📚 Support multiple technical topics with syntax highlighting and code examples
4. 🎯 Provide clear learning paths with tip/warning/remember visual cues
5. 📖 Follow professional publishing standards (Wiley-style structure with Parts and chapters)
