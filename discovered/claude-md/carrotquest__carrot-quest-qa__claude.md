# Carrot Quest - QA Engineering

## Project Overview

This workspace contains QA engineering workflows and tools for **Carrot Quest** - a customer messaging and engagement platform. Carrot Quest provides SDKs for iOS and Android that enable in-app messaging, chat, notifications, and user analytics.

## About Me

I'm Valya, QA Engineer at Carrot Quest, specializing in:
- Mobile SDK automation testing (iOS/Android)
- Web application testing (operator panels, chat widgets, bot builder)
- Manual and exploratory testing of new features
- Bug investigation and root cause analysis (mobile & web)
- Quality process automation and tooling
- PR analysis and test plan generation

## Technical Context

### Carrot Quest SDK
**Purpose**: Mobile SDKs that integrate messaging functionality into client apps
**Key Features**:
- In-app chat with WebView and native SwiftUI implementations
- Push notifications and in-app notifications
- User identification and segmentation
- Message delivery tracking
- Third-party integrations (Chargebee, Mindbox, Telegram)
