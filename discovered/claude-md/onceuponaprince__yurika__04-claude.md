# CLAUDE.md - yurika.space

This document is the Engineering Source of Truth for yurika.space. It is designed to be ingested by AI coding assistants (Claude Code, Cursor, Copilot) so generated code remains aligned with the technical architecture and the Retro-Futuristic Terminal aesthetic.

## 1. Project Overview and Tech Stack

Blockchain-powered fractionalized domain marketplace and founder accelerator.

- **Frontend:** Next.js 14+ (App Router), TypeScript, Tailwind CSS, Framer Motion (for glitch animations).
- **Backend:** Django 5.x, Django REST Framework (DRF), SimpleJWT for Web3-hybrid auth.
- **Databases:**
  - PostgreSQL + PostGIS: Relational data and transactional records.
  - Neo4j (via `neomodel`): Knowledge graph for founder/investor networking.
- **Web3:** Solidity (Hardhat/Foundry), Wagmi/Viem for frontend hooks.
- **Infrastructure:** Docker Compose for local development, Base (L2) for smart contracts.
