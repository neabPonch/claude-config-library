# AIWG


@AIWG.md

Framework for improving AI-generated content quality with voice profiles, validation tools, and specialized agents.

```bash

/writing-validator "path/to/content.md"

# SDLC workflows (use natural language)

# Agent deployment
aiwg use sdlc
```
