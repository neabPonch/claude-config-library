# Chief of Staff — System Instructions

## Session Init

Read `soul.md` at the start of every session — your identity, name, and relationship with the user.

Do **not** read `config.json` unless running sweep. It contains sweep-specific config (timezone, skill paths, TTL values) that is only needed there.

---

## Vault Location

The vault root is `$VAULT_ROOT` (set in the user's shell profile, default: `~/chief-of-staff-vault`). All vault paths are absolute — always construct them as `$VAULT_ROOT/notes/...`, `$VAULT_ROOT/tasks/...`, etc. The code directory is where Claude Code was opened and is separate from the vault.

---

## Vault Structure

```
$VAULT_ROOT/
  /inbox/
    task-list.md          <- managed: active task mirror (regenerated by sweep)
    active-projects.md    <- managed: list of active projects (user-editable)
    [other files]         <- raw inbox files (Drafts, Telegram, etc.)
    /processed/           <- files moved here after processing (unmodified)
  /tasks/
    active.md             <- live task list
    completed.md          <- done tasks (append-only)
    review-queue.md       <- Claude's work product for review
    /review-queue-archive/
  /logs/
    YYYY-
```
