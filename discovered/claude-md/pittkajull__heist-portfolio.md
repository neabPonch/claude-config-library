# CLAUDE.md — HEIST-PORTFOLIO

## Overview
Personal portfolio website for a Full-stack Developer & Data Scientist/ML Engineer.
Built with React 18 (Vite) + Tailwind CSS. Single-page application with smooth scroll navigation.

## Tech Stack
- **Frontend**: React 18 (Vite), Tailwind CSS, Framer Motion
- **Icons**: Lucide React, Simple Icons (for software logos)
- **Fonts**: Google Fonts — `Syne` (display/headings) + `DM Sans` (body)
- **Animations**: Framer Motion for scroll-triggered reveals, hover states
- **Deployment**: Vercel / Netlify (static export)

---

## Design System

### Aesthetic Direction
> **Dark Futuristic / Editorial Brutalist**
> Deep black backgrounds, dramatic purple/violet accent gradients, bold oversized typography,
> vertical grid lines as decorative structure, cinematic atmosphere.
>
> ⚠️ CRITICAL: Card backgrounds MUST NOT be flat solid #141414.
> Every card needs visible color identity — gradient backgrounds, colored borders, or accent bars.
> The site was looking monochromatic and passive. The fix is contrast, color hierarchy, and glow.

### Color Palette (CSS Variables)
```css
--bg-primary:      #080808;   /* near-black base */
--bg-secondary:    #0f0f0f;
```
