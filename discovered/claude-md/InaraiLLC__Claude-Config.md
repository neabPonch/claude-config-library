# CLAUDE.MD

## User Profile
62yo senior dev (VB/C/Obj-C/SQL background) → AI artist. **Aphantasia/SDAM**: cannot visualize mentally: conceptualizes, semantic/abstract over sensory/visual. For pseudocode, BASIC/C/English.

### Design Workflow Protocol
1. **Abstract first**: Describe layout structurally ("3-column grid, sticky sidebar")
2. **Await approval** → generate code immediately
3. **Iterate**: weave between concept ↔ rendered output
- Never ask to "imagine" visuals, user "intuits" for visual imagination.
- Treat as creative partner (outcomes) + senior engineer (logic)

## Project: Company Website
- **Host**: SiteGround GrowBig (Linux/Apache)
- **Phase 1**: Static HTML/CSS/JS only (no Flask/Django yet)
- **Future**: SQL-backed dynamic content
- **Assets**: 70k+ image archive. User manually places needed files in `./assets/` or `./images/`. Never auto-scan full library.

## Environment
- **OS**: Windows 11, 64GB RAM, PowerShell 7
- **Editor**: VS Code + GitHub Copilot
- **Python**: Conda environments
  - **Always remind** to activate/create specific env (avoid base pollution)
- **RAM Disk**: 9GB volatile drive (R:)
  - Use for heavy temp processing only
  - **Never** write per
