# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Build Commands

This is an Unreal Engine 5.7 C++ project. Build via:

- **Editor + Game**: Open `unreal_game_dev.uproject` in Unreal Editor (UE 5.7 required); it will prompt to compile.
- **Command-line build** (from UE install root):
  ```
  UnrealBuildTool.exe unreal_game_devEditor Win64 Development "C:\...\unreal_game_dev\unreal_game_dev.uproject"
  ```
- **Live Coding**: Enabled by default (`Intermediate/Build/.../LiveCodingInfo.json` present). Use Ctrl+Alt+F11 inside the editor to hot-reload C++ changes.
- **Visual Studio / Rider**: Open the `.sln` generated by right-clicking the `.uproject` → "Generate Visual Studio project files."

There is no separate lint or test pipeline; validation happens through Unreal's compile-time UCLASS/UPROPERTY macros and the editor's Blueprint compilation.

## Architecture

This is a top-down RTS prototype. All C++ classes are `UCLASS(abstract)` — logic lives in C++ and is completed by a corresponding Blueprint subclass in `Content/`.
