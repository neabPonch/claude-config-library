# Ryan.care Photography Blog

## Project Overview

Ryan.care is a photography blog and portfolio website showcasing photography work, including a gallery, print shop, and blog posts. The site uses a clean, modern design with a dark theme and minimal aesthetic.

## Tech Stack

- **Frontend**: Static HTML/CSS (no build process)
- **Styling**: Inline CSS with modern CSS features (flexbox, backdrop-filter)
- **Images**: Stored in `/images/` directory
- **Deployment**: Static hosting (GitHub Pages compatible)

## Project Structure

```
/
├── index.html              # Homepage
├── gallery.html            # Photo gallery
├── print-shop.html         # Print shop page
├── blog.html               # Blog listing
├── flower_blog.html        # Flower photography blog post
├── posterization_blog.html # Posterization technique blog post
├── about.html              # About page
├── images/                 # Image assets
│   └── logo.jpg           # Site logo
├── IMAGE_MAPPING.json      # Image metadata/mapping
├── CNAME                   # Custom domain configuration
└── CLAUDE.MD              # This file
```

## Design System

### Color Palette
- **Background**: `#000` (black)
- **Text**: `#fff`
